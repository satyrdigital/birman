# Типографічні розкладки для macOS, Windows і Linux

Форк проєкту [neochief/ukrainian-typographic-layouts](https://github.com/neochief/ukrainian-typographic-layouts), що походить від типографічних розкладок Іллі Бірмана. Мета — зручне введення кирилиці, українських літер та типографічних символів.

## macOS — актуальна версія

Для macOS доступний пакет **2.0.1**. Основна розкладка має назву **«Кирилиця»** та нейтральний значок **Ѣ**. Набір клавіш не змінено: збережено базову розкладку та додаткові українські літери через **Option (⌥)**.

Інструкція зі встановлення, оновлення попередньої версії та перевірки: [Mac/README.md](Mac/README.md).

Пакет створюється штатними засобами Apple в GitHub Actions. Він не запускає жодних служб у тлі, не перехоплює клавіші та не змінює системні комбінації.

## Windows

У `Windows/dst/` зберігаються початкові матеріали проєкту. **Їх ще не перевірено в межах модернізації цього форка**, тому не слід вважати готові виконувані файли перевіреним інсталятором.

## Linux (Ubuntu)

У `Ubuntu/` містяться успадковані сценарії. Вони ще не пройшли аудит та модернізацію. Не запускайте їх із правами адміністратора без попередньої перевірки.

## Статус і безпека

- Перевірена автоматична збірка існує лише для пакета macOS; роботу на конкретному комп'ютері потрібно підтвердити окремо.
- Застарілий `Mac/dst/UkrainianTypographicLayouts.dmg` не використовується для нових установлень.
- Проєкт поширюється з вихідними файлами розкладок і відкритим сценарієм складання пакета.
